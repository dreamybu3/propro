# GapLens v2: method-level related work

This review was completed on 2026-10-22 UTC, before examination of the new v2 holdout results. It concerns retrospective univariate block imputation, not forecasting. References `[R1]`–`[R10]` identify the pinned, inspected materials in [SOURCES.md](SOURCES.md). The original three NAB streams are development data. The review does not establish algorithmic novelty or exhaust all prior work.

## Assessment and research question

AnalogBridge combines known ideas: retrieval of historical analogs, correction using observed context, an ensemble mean and dispersion, and residual-based calibration. V2's proposed temporal exclusion is also established: TKCM's inspected implementation explicitly selects non-overlapping historical patterns, and STUMPY's match search suppresses an exclusion zone around each selected match. AnDA supplies particularly close prior art for incremental analog correction and retrospective ensemble smoothing. SSA supplies close prior art for combining predictions from both sides and reconstructing missing entries in a learned trajectory subspace.

Accordingly, an appropriate contribution is an independently implemented, auditable combination for a restricted information setting, supported by an evaluation of reliability and failure conditions. A different name, different programming language, or absence of an exact formula in the sources inspected here would not establish novelty.

**Research question.** In retrospective block imputation with a fixed historical reference, does selecting temporally separated analog windows improve the usefulness of whole-block uncertainty compared with v1, and does using more recent genuinely observed calibration blocks improve adaptation to temporal change?

**Testable mechanism hypothesis.** V1 can select many adjacent reference windows from one episode. This can make apparent neighbor count larger than the number of distinct episodes and make empirical neighbor dispersion less informative. Temporal separation might improve uncertainty–width tradeoffs, but can also discard the best matches and increase point error. Recent calibration might improve coverage under change, but reduces the effective calibration sample and can make estimates less stable. These are hypotheses, not established explanations of every v1 coverage failure. Fewer overlapping windows do not establish statistical independence.

The two components need separate ablations: unchanged v1; exclusion only; recent calibration only; their combination. Freeze retrieval distance, endpoint correction, candidate budget and other unrelated choices while testing exclusion. Report selected-neighbor count, separation, nearest distance, uncertainty, coverage and service fraction. Compare interval widths at comparable achieved coverage; a wider interval that merely reaches a higher coverage is not an efficiency gain. The final selection rule and quantitative success criteria belong in the preregistered experiment protocol, not in this literature review.

## Information available to each method

A complete input example consists of historical measured reference values, the timestamps, and the measured values outside all simultaneously masked intervals. Values hidden for evaluation cannot enter fitting, context, retrieval, preprocessing, calibration or hyperparameter selection. The right context is legitimate because the task is retrospective. An earlier imputed value is not an observation or a calibration target.

For a controlled local-context comparison, the conditional-PCA, direct retrieval and AnalogBridge methods must receive the same left/right context positions. A smoother may consume a longer observed part of the target series only if this is a declared common information allowance; it is then a broader-information baseline, not a numerically identical context experiment. Model parameters should be learned on the permitted training/development part. Applying a frozen smoother to observed holdout context is distinct from refitting model parameters on the entire holdout.

## Closest retrieval comparisons

A direct historical-context KNN baseline should compare the same complete reference windows with the same finite observed query context, then average the associated hidden-block trajectories. It should use the same candidate limit and a documented neighbor/weight tuning budget as AnalogBridge. Removing the endpoint correction isolates the effect of that correction. Adding temporal exclusion to this baseline can isolate whether any benefit comes from neighbor selection rather than from the bridge itself.

For reference block trajectory `a_j(t)`, observed query endpoints `q_left, q_right`, and candidate endpoints `a_j,left, a_j,right`, AnalogBridge adds

```text
a'_j(t) = a_j(t)
          + (1 − u_t) (q_left  − a_j,left)
          +      u_t  (q_right − a_j,right),
u_t = t / (L + 1),  t = 1, ..., L.
```

This is a linearly varying residual correction. AnDA's incremental forecasts demonstrate the broader analog-offset idea; Rssa demonstrates two-sided linear blending. Neither observation proves that those inspected implementations use this exact two-endpoint formula. Conversely, this review's failure to identify the exact formula elsewhere does not establish its novelty.

TKCM's inspected diversity step is more than an informal heuristic: its recurrence includes the predecessor `j − l` when accepting a pattern of length `l`, then backtracks to obtain the K patterns. GapLens's proposed greedy exclusion is not equivalent to that optimal sum-of-distances selection. The scientific question is its usefulness under GapLens's information constraints, not priority for non-overlapping pattern selection.

## Why a low-rank competitor matters

Historical-window retrieval is a local estimate of the relationship between context and missing values. A conditional low-rank trajectory model estimates a global relationship from the same windows and can provide a challenging, inexpensive counterexample to any claim that explicit nearest-neighbor retrieval is necessary.

The implemented comparator learns a column mean and a PCA basis `B` from complete **training-only** windows after scalar normalization. Partition the basis rows into observed coordinates `B_O` and missing coordinates `B_M`. It fits latent coefficients to the observed context with ridge regularization, then reconstructs the missing coordinates:

```text
a = solve(B_O.T B_O + ridge I, B_O.T (query_O − mean_O)),
prediction_M = mean_M + B_M a.
```

These equations are in the training-normalized coordinates; the output is transformed back to the original units. This is regularized subspace reconstruction, not Gaussian conditioning with the full empirical covariance and not maximum-likelihood probabilistic PCA. The rank and regularization must be selected without final-holdout values. The code uses a numerical solver instead of explicitly forming an inverse. Its uncertainty scale comes from training reconstruction residuals plus a noise floor and still requires separate calibration. The comparator is not a reproduction of Rssa or DynaMMo. Its strength must ultimately be shown by tuning and results; this review cannot guarantee it wins.

Include linear interpolation and a seasonal baseline even if they sometimes win. Tune a structural local-level/local-linear/seasonal smoother within a documented budget rather than choosing an intentionally poor state-space configuration. Preserve ExtraTrees and v1 on the identical v2 masks. A neural method is not necessary to make this particular small-data, univariate, CPU comparison credible, and this does not imply that neural imputers are intrinsically unsuitable or weaker. A publication claiming broad state of the art would require a wider competitor study.

## Whole-block uncertainty and sequential calibration

`[R8]`–`[R10]` separate three issues that must not be conflated:

1. **The prediction object.** Pointwise interval coverage does not imply that all values of a missing block are covered. GapLens uses one score per block, `S_i = max_t |y_it − prediction_it| / scale_it`, so a threshold on `S_i` describes simultaneous coverage of that block. Treating a vector-valued target as one example and calibrating its scalar score is a standard conformal construction. It is not a new uncertainty principle.
2. **The data assumptions.** With a fixed trained predictor/scale and exchangeable calibration/new block scores, using the finite-sample order statistic at `ceil((n + 1)(1 − alpha))` gives the usual marginal rank argument for a new block. The score may contain temporal dependence inside the block. The required exchangeability is across calibration/new **blocks**; overlapping or temporally shifted blocks do not automatically have it. If the rank exceeds `n`, a finite sample quantile cannot support that nominal rank: use an unbounded set or explicitly decline that finite interval.
3. **Adaptation to time.** Replacing old calibration blocks with more recent ones can be useful empirically, but does not itself prove exchangeability, independence, or a time-series coverage theorem. A recent calibration batch before an evaluation origin is different from an online algorithm that receives each preceding test target as feedback.

EnbPI `[R8]` uses bootstrap-ensemble leave-one-out residuals and a sliding residual window updated after genuine new targets arrive. Its paper's Theorem 1 assumes a stationary strongly mixing error process with summable mixing coefficients, a Lipschitz error CDF, and an estimator-accuracy condition. It bounds approximate marginal validity; the authors explicitly note that their deployed intervals do not include the bound's correction. Its scalar marginal-coverage result is not a guarantee of simultaneous coverage of arbitrary GapLens blocks.

SPCI `[R9]` predicts conditional residual quantiles using residual history rather than only taking a recent empirical quantile. Its stated asymptotic conditional-coverage theorem uses assumptions about residual dependence, quantile-estimator weights and distributional regularity. A rolling maximum-residual quantile for GapLens is therefore neither an implementation of SPCI nor entitled to its guarantee.

CFRNN `[R10]` is useful independent confirmation that whole-trajectory coverage is a distinct target: its author code computes both individual and joint coverage and uses a Bonferroni `alpha / horizon` correction for horizon-specific intervals. It forecasts after a prefix, whereas GapLens has both sides of a gap. The correction is also different from GapLens's single maximum score. No empirical comparison with CFRNN is implied by citing it.

A valid rolling evaluation must record when calibration truth became available. Artificial gaps may be scored retrospectively by the evaluator, but their hidden targets may not be fed back to the method unless the protocol explicitly models their later measurement/revelation. Previously repaired estimates are never calibration truth. For simultaneous outages, one gap's hidden truth cannot enter another gap's observed context. Abstention must be reported alongside error and coverage on accepted cases; service fraction is part of the result.

## Scope of the evidence

This review inspected three complete primary papers (AnDA, EnbPI, SPCI), substantive original-author or package-author code for AnDA, DynaMMo, Rssa, imputeTS, PAnEn, STUMPY and CFRNN, and the explicitly attributed TKCM adaptation. Source versions and access limitations are recorded below. It did not run every cited package, independently reproduce their published benchmarks, verify every proof, or prove that any proposed v2 change improves performance. Those would be different claims requiring different evidence.

The defensible contribution can remain substantial if the modification fails: provenance-safe software, controlled and reproducible comparisons, measurement of coverage/service tradeoffs, and a clear account of when a simpler method is preferable. Positive results on a chosen finite corpus still do not establish universal superiority or publication-ready novelty.

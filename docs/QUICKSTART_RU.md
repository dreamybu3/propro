# GapLens: запуск и работа

GapLens восстанавливает пропуски во временном ряду по похожим историческим фрагментам. Результат — CSV, JSON с объяснением и интерактивный HTML. Нужны наблюдения с обеих сторон пропуска: это инструмент для ретроспективного анализа.

## Windows: точные команды

Установите Python 3.12 с официального python.org. Откройте PowerShell в папке проекта, где находятся `pyproject.toml` и `README.md`. На этапе установки зависимостей нужен Интернет; данные уже включены в проект. GPU не используется.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --require-hashes -r requirements.lock
.\.venv\Scripts\python.exe -m pip install --no-deps -e .
.\.venv\Scripts\gaplens.exe repair --reference examples/reference.csv --input examples/with_gaps.csv --output my-repair --require-complete
Invoke-Item .\my-repair\report.html
```

Активация окружения не нужна, поэтому менять PowerShell ExecutionPolicy не требуется. Если `my-repair` уже существует, укажите новую папку либо осознанно добавьте `--overwrite`. Эта опция заменяет только `repaired.csv`, `report.json`, `report.html`; входные файлы защищены.

Проверено фактически: Linux x86-64, Python 3.12.14, установка, полный эксперимент, CLI и экспорт. Windows пока не запускалась; подготовлены переносимые команды и CI-конфигурация. Не представляйте совместимость с Windows как уже измеренный результат.

## Что посмотреть

В демонстрации скрыты 42 известных значения реального пассажиропотока NYC. Ожидаемый итог: восстановлены 3 из 3 пропусков, сохранены все 2 022 исходных наблюдения. В HTML выберите пропуск, проверьте кривую, интервал и список исторических соседей. CSV содержит исходные значения, оценки и статусы; JSON — параметры, контрольные суммы и калибровку.

Готовый отчёт также находится в `results/demo/report.html`. Для просмотра не нужен сервер. `examples/ground_truth.csv` — отдельная истинная последовательность для проверки демонстрации; алгоритм её не читает.

## Проверки и воспроизведение исследования

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe scripts/run_experiments.py --config configs/benchmark.json --output results/reproduction
.\.venv\Scripts\python.exe scripts/plot_results.py --input results/reproduction
```

Оригинальные измерения сохранены в `results/benchmark`; новая команда не заменяет их. При повторном запуске выбирайте новый каталог. На облачной Linux-машине полный эксперимент занял около 100 секунд и 259 МиБ пиковой памяти процесса; время на вашем ноутбуке не измерялось.

Упрощённый способ с установленным `uv` одинаков по платформам:

```powershell
uv sync --frozen
uv run gaplens repair --reference examples/reference.csv --input examples/with_gaps.csv --output my-repair --require-complete
uv run python -m pytest -q
```

## Свои данные

Нужны два CSV с колонками `timestamp,value`:

1. `history.csv`: более ранняя история; последние 25% используются для калибровки.
2. `incomplete.csv`: строго более поздний ряд; пропуски обозначены пустыми ячейками `value`.

Время должно возрастать без дубликатов, шаг и сетка времени должны совпадать. Для отсутствующих временных меток заранее вставьте строки с пустым значением. Программа не сортирует, не удаляет выбросы и не меняет шаг автоматически. Без достаточной истории и полного наблюдаемого контекста она оставит пропуск и объяснит причину.

```powershell
.\.venv\Scripts\gaplens.exe repair --reference history.csv --input incomplete.csv --output own-result --method analog --neighbors 12 --context 6 --max-gap 48 --alpha 0.1
```

Длина пропуска и контекст измеряются в отсчётах. `--method linear` и `--method extra-trees` запускают базовые методы. Все настройки доступны через `--help`, исходники редактировать не нужно. Код возврата 2 означает ошибку ввода; с `--require-complete` код 3 означает частичный результат с оставшимися пропусками. Артефакты частичного результата сохраняются.

## Что говорить о результате честно

В выполненном сравнении собственный метод снизил нормированную MAE на 51,8% относительно линейной интерполяции и на 14,4% относительно ExtraTrees. Это результат на трёх выбранных реальных рядах с искусственными масками. Полная гипотеза не подтвердилась: интервалы оказались шире, чем ожидалось, и не достигли целевых 90% покрытия; для NYC покрытие целого пропуска — лишь 78,7%.
